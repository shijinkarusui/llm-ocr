# IPA 附加符号转录规范（Unicode 组合）

本规范是 `prompts/ocr_system.md`“国际音标附加符号识读”一节的机器可检版本。
输出为纯 Markdown 正文，不使用 LaTeX 位置语法：`\underset`、`\overset`、
`$...$`、`\[...\]` 一律禁用。所有附加符号一律直接使用正确的 IPA Unicode
字符，与基字符组合成一个字形单位，不得拆分、丢弃、移位，不得用普通拉丁
字母、前后并列、描述性文字替代。

## 组合原则

1. 唇化一律写 `ʷ`（如 `[tʷ]`），送气一律写 `ʰ`（如 `[kʰ]`），腭化一律写 `ʲ`
   （如 `ɕʲ`）；不得写成 `w`、`h`、`j`、`^w`、`_w` 等 ASCII 形式。
2. 必须严格区分基字符与附加符号、附加符号与附加符号之间的差异，包括但不限于：
   鼻化、唇化、腭化、软腭化、咽化、齿化、送气、不除阻、清化、浊化、成音节、
   非音节、中央化、前移、后移、圆唇、展唇、长音、半长音、声调符号。
3. 小型附标字母仍是音标的一部分：送气、唇化、腭化等上标小字必须保留为上标
   形式的附加符号；长度 `ː` 不得写成冒号 `:`，重音 `ˈ` 不得写成撇号，鼻化组合符
   不得写成阴平 `-`，声调 `ˊ ˋ` 不得写成重音，前移后移等组合附加符不得丢弃。
4. 位置关系优先于字形相似性：附加于字符上方、下方、左方、右方的小符号，必须
   判定为该位置对应的附加符号，不得按视觉近似写成无关标点或正文；实在无法
   确定时保留最可信的可见形式，但不得把两可符号全局统一写成其中一种。

## 禁止写法

- ASCII 位置替代：`[t_w]`、`[k_w]`、`[tw]`、`[k^h]`、`^jɕ`、`_nt` 一律禁止；
  应按原图写成 `tʷ`、`kʰ`、`ɕʲ` 等 Unicode 组合形式。
- LaTeX 残留：`\underset`、`\overset`、未转义的 `$`、`\[`、`\]` 一律禁止；
  方括号是音标转写的一部分，可以直接出现在正文（如 `[tʷ]`），但括号内不得
  使用 ASCII `^`/`_`。
- 拆分与游离：基字符与组合附加符之间不得加入空格；组合附加符不得出现在行首、
  空格或标点之后而无基字符（游离组合符）。
- 描述性替代：不得用“鼻化”“唇化”“送气”等文字描述代替符号本身。

## IPA 原样保留清单

以下符号和组合不得替换、拆散、ASCII 化或丢失：

`ʔ ɦ ɥ ɤ ɕ ŋ ɲ ʈ ʂ ʐ ɹ ɿ ʅ ɔ ɛ ɑ β ɓ ɗ ɭ ɳ ɰ ɣ ʃ ʒ ʁ ɸ θ ð ʰ ʷ ʲ ː ˈ ˌ ̃ ̚ ³⁵ tɕ tʂ tɕ' kʰ`

特别注意：`ʷ`、`ʲ`、`ʰ`、`̃`、`̚`、`ː`、`ˈ`、`³⁵` 一律按 Unicode 原样保留；
圆唇化小 `w` 若是原图中的独立微型附标，应按位置关系判定为 `ʷ` 并与基符号直接
组合（如 `[tʷ]`），不得拼接为 `[tɕ'w]`、`[tɕ'_w]` 之类。

## 校验要点

校验器（`src/check_notation.py` 的 `check_file`/`check_text`）应报告：ASCII 位置替代、
丢失附标的 `[tw]` 类形式、LaTeX 残留、游离或拆分的组合附加符、未配对的括号。
校验结果只指出可疑位置；最终是否为真实附标仍以原书光栅图为准。
