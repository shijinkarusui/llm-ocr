# 标号位置规范

本规范用于中文语音学扫描页中的 IPA 微型附标。先按扫描图判断附标相对原符号 `Y` 的几何位置，再使用下表的唯一写法。每个完整标注都是一个 LaTeX 行内公式，必须由一对 `$...$` 包住；不要用显示公式定界符 `\[...\]`，也不要把附标退化成普通 Markdown 文本。

## 六位置映射

| 扫描位置 | 唯一映射 | 正例 | 反例（禁止） |
| --- | --- | --- | --- |
| 正下 | `$\underset{x}{Y}$` | `$[\underset{w}{t}]$` | `[t_w]`；`[tw]` |
| 正上 | `$\overset{x}{Y}$` | `$[\overset{h}{k}]$` | `[k^h]`；`[kh]` |
| 左上 | `${}^{x}Y$` | `${}^{j}ɕ$` | `^jɕ`；`jɕ` |
| 左下 | `${}_{x}Y$` | `${}_{n}t$` | `_nt`；`nt` |
| 右上 | `$Y^{x}$` | `$k^{ʰ}$` | `$k^h$`；`kh` |
| 右下 | `$Y_{x}$` | `$Y_{w}$` | `$Y_w$`；`Yw` |

表中的 `x` 是附标，`Y` 是承载附标的原符号；二者都要按原图替换。即使附标只有一个字符，也保留花括号，避免多字符 IPA 被错误解析。`[t_w]`、`[k_w]`、`[d_w]`、`[tc_w]` 及同类带 ASCII 下划线或脱离公式的写法一律禁止；`[tw]` 这类把位置附标直接丢掉的写法也禁止。

## 圆唇化重点

原图中声母右下或下方的微型 `w` 表示圆唇化时，依照图上的实际相对位置记录。例如：

- `$[\underset{w}{t}]$`
- `$[\underset{w}{k}]$`
- `$[\underset{w}{tɕ'}]$`

`tɕ'` 是一个完整的 IPA 基符号串；不要拆成普通文本，也不要把 `w` 拼接为 `[tɕ'w]`、`[tɕ'_w]` 或 `[tɕ'w]`。若图中 `w` 明确在右上、左上、左下或右下，不能因为“圆唇化”这一含义而套用正下模板，必须按几何位置改用对应模板。

## 公式和括号规则

1. 每一个含位置附标的单元都完整包在单个 `$...$` 内，例如 `$[\underset{w}{t}]$`；方括号是音标转写的一部分，可以放在数学定界符内。
2. `\underset` 和 `\overset` 必须在 `$...$` 内，并且各有成对的 `{附标}` 与 `{原符号}` 参数。
3. 左上、左下、右上、右下写法中的花括号必须成对：`${}^{x}Y$`、`${}_{x}Y$`、`$Y^{x}$`、`$Y_{x}$`。禁止 `$Y^x$`、`$Y_x$` 这类省略参数花括号的写法。
4. 检查公式时，`$`、`{}`、`[]` 都要配对；普通正文中的方括号也不得缺失。反斜杠转义的 `$` 不算公式定界符。
5. 位置优先于线性顺序：不能把扫描图中的正下、正上、左上、左下、右上、右下附标写成相邻字符。未确认位置时宁可标记待复核，也不能臆造位置。
6. `^`、`_` 只能作为受花括号保护的 LaTeX 位置语法出现；IPA 本身的 Unicode 上标、下标或组合附加符不是 ASCII `^`、`_`，应原样保留。

## IPA 原样保留清单

以下符号和组合不得替换、拆散、ASCII 化或丢失：

`ʔ ɦ ɥ ɤ ɕ ŋ ɲ ʈ ʂ ʐ ɹ ɿ ʅ ɔ ɛ ɑ β ɓ ɗ ɭ ɳ ɰ ɣ ʃ ʒ ʁ ɸ θ ð ɥ ʰ ʷ ʲ ː ˈ ˌ ̃ ̚ ³⁵ tɕ tʂ tɕ' kʰ`

特别注意：`ʷ`、`ʲ`、`ʰ`、`̃`、`̚`、`ː`、`ˈ`、`³⁵` 若在原图中是 Unicode IPA 标记，按图原样保留；只有图上另有独立微型附标时，才按六位置模板写成 LaTeX。声调数字、长音、重音、送气和复杂基符号均不可凭常见写法改动。

## 校验要点

校验器应报告：禁用的方括号附标、丢失附标的 `[tw]` 类形式、公式外的 `\underset`/`\overset`、未配对的 `$` 或花括号、未加花括号的孤立 `^`/`_`，以及显示公式定界符。校验结果只指出可疑位置；最终是否为真实附标仍以原书光栅图为准。
